# 项目接入指南

一个需求/项目 = `projects/` 下一个文件夹。场景、人物、走动、气泡、详情抽屉全部由
`project.js` 数据驱动，引擎代码不需要改动。

## projectID 是什么？

**projectID 就是 `projects/` 下的文件夹名**，自己命名（英文）即可，不需要去别处申请或查询。
系统按文件夹名加载项目，`project.js` 里的 `id` 字段可省略（始终以文件夹名为准）。

## 接入新项目（3 步）

1. **复制模板**：把 `projects/_template` 复制为 `projects/<文件夹名>`（英文命名）。
2. **填写数据**：编辑其中的 `project.js`，按文件内注释填写三块内容：
   - `roles`：角色（2~10 个，工位自动分两排摆放）
   - `files`：文件版本库（文档/代码 diff/设计稿/日志，含每个版本的修改原因）
   - `script`：交接剧本（`phase` 换阶段 / `work` 干活 / `handoff` 走动交接，支持 bug 打回回路）
3. **注册到下拉框（可选）**：打开旁边的 `projects/registry.js` 加一行：

   ```js
   window.PROJECT_REGISTRY = {
     'order-tracking':   '📦 订单跟踪功能 v1.2.0 · 8 角色全流程',
     'official-website': '🌐 官网改版 v2.0 · 5 角色精简流程',
     'my-project':       '🚀 我的新需求 · 3 角色',        // ← 键 = 文件夹名
   };
   ```

访问 `index.html?project=<文件夹名>`；已注册的项目直接用页面顶栏右侧下拉框切换。
不注册也能用 URL 打开（下拉框会显示"当前项目（未注册）"提示）。

## 目录说明

| 路径 | 作用 |
| --- | --- |
| `projects/<文件夹名>/project.js` | 项目数据：角色 / 文件版本库 / 交接剧本 |
| `projects/registry.js` | 项目注册表（下拉框菜单，键 = 文件夹名） |
| `js/boot.js` | 启动加载器：按 `?project=` 加载对应文件夹 |
| `js/data.js` | 通用数据层：校验项目数据、按角色数自动排工位 |
| `js/scene.js` `js/panel.js` `js/sim.js` `js/main.js` | 场景 / 详情抽屉 / 模拟引擎 / 主控（与具体项目无关） |

## 对接真实智能体系统（可选进阶）

原型由剧本驱动；接真实系统时保留 UI 层，把 `js/sim.js` 的剧本执行器替换为订阅你们
真实的任务/消息事件流，向同一份 `CD.state` 写入两类数据即可：

- **消息**：`{ from角色, to角色, 内容, 附件文件[] }` → 驱动走动 + 气泡 + 时间线
- **文件**：`{ 路径, 负责角色, 版本序列, 状态 }` → 驱动文件工作台 + 版本 diff

事件流落库后，同样可以按时间轴重放整个协作过程。
